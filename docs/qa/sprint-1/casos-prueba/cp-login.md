# Prueba de inicio de sesion

# Objetivos
Validar el funcionamiento adecuado de inicio de sesion 

## Casos

### Inicio de sesion valido o no valido

- el usuario existe
- el usaurio se encuentra disponible
- control de roles
- comprobar funcionamiento de reset de contraseña
- ayudas visuales para usuarios para ver contraseña
- ¿ Que pasa si ingresamos  credenciales erroneas?

### Pasos

1. Ir al modulo de inicio de sesion
2. ingresar credenciales correctas
3. Ingresar por el medio de boton
